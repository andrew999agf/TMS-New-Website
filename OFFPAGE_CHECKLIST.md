# Off-page SEO checklist (things only the firm can do)

The site now gives Google everything it can read on its own. These items live outside the code and are what the larger firms in the comparison screenshots have done.

## 1. Google Business Profile (the card with stars, Directions and Call)
- [ ] At business.google.com, claim or create **T. Maxwell Smith, PLLC**.
- [ ] Add all three locations, with name, address and phone **exactly** as the site shows them (Meridian 115 W. River Street · (254) 435-4288; Fort Worth 1612 Summit Ave., Suite 200 · (817) 348-8325; Weatherford 100 Austin Avenue, Suite 101 · (817) 475-5522). Mismatched punctuation counts.
- [ ] Verify each (postcard, phone or video). Set hours; Weatherford as by appointment.
- [ ] Category: Law firm; add Personal injury attorney, Civil law attorney, Appellate… as secondary.
- [ ] Add photos of each office and the attorney. Link each profile to its page: /locations/fort-worth, /locations/meridian, /locations/weatherford.
- [ ] Ask satisfied clients for reviews; reply to every one. Reviews are the single biggest visual difference in the search results.

## 2. Google Search Console
- [ ] Add the property for **www.texaslawsmith.com** (the canonical host) and, as a domain property, texaslawsmith.com.
- [ ] Submit https://www.texaslawsmith.com/sitemap.xml.
- [ ] Request indexing of the home page, /contact and the three /locations pages.
- [ ] In Vercel → Domains, make sure **texaslawsmith.com redirects to www.texaslawsmith.com** (one host serves pages; the other only redirects).

## 3. Bing Webmaster Tools
- [ ] Import the site from Search Console (one click) and submit the same sitemap.

## 4. Directory and profile links (fill the social/profile fields in Admin → Website Management so they appear in the schema)
- [ ] State Bar of Texas Find-a-Lawyer profile — confirm the listed address and phone match.
- [ ] Avvo, Justia, FindLaw, Lawyers.com, Super Lawyers (where a profile exists).
- [ ] LinkedIn (firm page and attorney), Facebook, Instagram, YouTube if used.
- [ ] Meridian Chamber of Commerce member listing — ask for the link to the site.
- [ ] Local and specialty bar association member directories.

## 5. Keep an eye on
- [ ] Search Console → Pages: anything "Crawled, not indexed" or "Duplicate" two weeks after launch.
- [ ] Search Console → Enhancements: Breadcrumbs, Sitelinks search box, FAQ (once FAQs are published) should show green.
